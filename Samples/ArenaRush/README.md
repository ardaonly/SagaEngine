# Arena Rush: Energy Core Challenge

Arena Rush is a canonical, non-playable foundation sample licensed under the MIT License; see `../LICENSE`.

The checked-in project proves current scene, input, primitive asset, runtime UI, package, managed-contract, Blocks discovery, and Inspector/source metadata paths. Its authoring configuration declares a 60-second challenge, a target of 100, cores worth 10, five active collectibles, and a two-second respawn delay.

Runtime collision, movement, timing, scoring, win/timeout execution, respawn execution, menu interaction, HUD/results updates, pooling, instrumentation, package transactions, editable Blocks, and standalone builds are intentionally deferred.
