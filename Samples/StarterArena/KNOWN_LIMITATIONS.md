# Known limitations

- Campaign 1 proves deterministic source-to-artifact tooling only. Runtime launch, Qt Editor integration, interactive door execution, and HUD work are later campaigns.
- The primitive sources intentionally cover only box and plane geometry with solid renderer materials.
- Physical input is currently limited to the strict `Keyboard E` reference fixture; logical gameplay remains bound to `Interact`.
- Cooked outputs are local GeneratedState and must not be committed.
