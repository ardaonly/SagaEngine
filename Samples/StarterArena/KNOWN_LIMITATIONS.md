# StarterArena Known Limitations

- The checked-in project is a source/tooling fixture, not a runtime launch.
- No current runtime scene, input, package, or script artifact contract is
  declared by this fixture.
- C# analysis or loose-source compilation does not prove runtime execution.
- No visible interaction, keyboard input, door behavior, HUD, Editor workflow,
  or complete Visual Blocks workflow is claimed.
- Generated output is not committed under the sample.
